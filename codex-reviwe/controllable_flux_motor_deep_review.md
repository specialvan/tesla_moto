# 可控磁通量电机技术开发方案深挖评审

## 0. 评审结论

Claude 初稿已经把可控磁通量电机的核心方向列出来了，但当前颗粒度还停留在“路线枚举 + 初步实验矩阵”。下一阶段应把每条路线拆成可验证假设、设计变量、模型输入、实验判据和淘汰门槛，避免过早进入硬件样机。

推荐采用三层路线并行推进：

1. **主线工程路线**：高凸极 IPMSM / PMaSynRM + MTPA / 弱磁 / MTPV + 非线性磁链表。这条路线成熟度最高，适合作为第一阶段主战场。
2. **中期增益路线**：磁路饱和协同设计 + 电压利用率提升 + 工况加权效率优化。这条路线决定能否从“会弱磁”提升到“弱磁效率更好”。
3. **长期探索路线**：可变磁化状态、混合励磁、绕组重构或多相控制。这些方案可能带来真实 `Ke/ψf` 可变能力，但复杂度、可靠性和安全风险高，初期只做模型和收益边界判断。

核心判断标准不是单点最高转速，而是：

- 高速区电压裕度是否足够；
- 弱磁铜耗和铁耗是否可接受；
- 低速峰值转矩是否被牺牲；
- 工况加权效率是否优于基线；
- 高温、低母线、短路、传感器误差下是否有可降级边界；
- 方案是否能被仿真、FEA 和低压台架逐级验证。

## 1. 技术路线总览

| 路线 | 本质 | 解决的问题 | 主要代价 | 阶段定位 |
|---|---|---|---|---|
| 负 d 轴弱磁 | 用 `id < 0` 降低合成 d 轴磁链 | 高速电压饱和、反电势压力 | 铜耗增加、退磁风险、低母线下裕度变小 | 短期主线 |
| MTPA/FW/MTPV 连续控制 | 在电流圆和电压椭圆内找最优电流角 | 全速域转矩和效率轨迹 | 标定复杂、切换平滑性要求高 | 短期主线 |
| SVPWM/过调制 | 提高直流母线电压利用率 | 延后弱磁进入点 | 谐波、NVH、电流畸变 | 短期增强 |
| 非线性磁链表 | 用 `λd/λq(id,iq,T)` 表达饱和 | 提高转矩、电压边界预测精度 | 数据采集和插值复杂 | 短中期主线 |
| 磁路饱和协同设计 | 让电机几何放大电流调磁能力 | 降低弱磁损耗、提高 CPSR | FEA 迭代、强度和退磁约束 | 中期突破 |
| 可变磁化状态 | 改变永磁体磁化档位 | 真实改变 `ψf/Ke` | 磁化脉冲、状态观测、寿命风险 | 长期预研 |
| 混合励磁 | 永磁 + 励磁绕组连续调磁 | 连续可调磁链 | 励磁损耗、热和结构复杂 | 长期预研 |
| 绕组重构/多相控制 | 改变等效匝数或磁场合成 | 改变 `Ke/Kt` 或容错运行 | 高压大电流开关、EMI、瞬态 | 长期预研 |

## 2. 主线一：IPMSM 负 d 轴弱磁

### 2.1 要验证的核心假设

负 d 轴电流可以降低 d 轴合成磁链，使高速区端电压需求下降，从而扩展恒功率速度范围。该方案不改变永磁体本身 `ψf`，改变的是合成磁链和端电压矢量。

### 2.2 关键设计变量

- `Rs`：影响铜耗和高温电压降。
- `Ld`：决定负 d 轴电流对磁链抵消的能力。
- `Lq`：决定磁阻转矩占比和凸极性。
- `ψf`：决定低速转矩能力和高速反电势压力。
- `Imax`：决定可用弱磁电流上限。
- `Vdc/Vmax`：决定高速电压约束。
- 退磁曲线：决定最大负 `id` 安全边界。
- 温度：影响电阻、永磁体磁链和退磁裕度。

### 2.3 建模颗粒度

第一版可以用线性 dq 模型：

```text
λd = Ld * id + ψf
λq = Lq * iq
vd = Rs * id - ωe * λq
vq = Rs * iq + ωe * λd
Te = 1.5 * p * (ψf * iq + (Ld - Lq) * id * iq)
```

第二版必须升级为非线性磁链表，否则高电流区会误判转矩和电压边界：

```text
λd = LUTd(id, iq, T)
λq = LUTq(id, iq, T)
Te = 1.5 * p * (iq * λd - id * λq)
```

### 2.4 实验设计

| 实验 | 输入 | 输出 | 合格判据 |
|---|---|---|---|
| FW-01 负 id 扫描 | `speed, torque_target, Vdc, Imax` | 可行 `id/iq` 区域 | 存在满足电压和电流约束的解 |
| FW-02 电压裕度曲线 | `speed sweep` | `MarginV(speed)` | 高速目标点 `MarginV >= 0` |
| FW-03 弱磁铜耗 | `id/iq/speed` | `Pcu` | 相比基线收益不被铜耗吞掉 |
| FW-04 退磁边界 | `Tmag, id_min, fault current` | 退磁风险等级 | 高温最大负 id 下仍有安全裕度 |

### 2.5 主要风险和对策

- **风险：弱磁扩速但铜耗过高。** 对策：引入工况权重，不只看最高速；对高速巡航点单独优化。
- **风险：负 id 触发退磁。** 对策：把退磁曲线作为硬约束，控制器中设置温度相关 `id_min(T)`。
- **风险：低母线高转速下电压饱和。** 对策：把 `Vdc_min` 纳入设计点，而不是只用额定母线。
- **风险：模型线性化导致边界乐观。** 对策：Phase 2 强制使用 `λd/λq` 查表复算。

### 2.6 进入和退出门槛

- 进入条件：已有基础电机参数 `Rs/Ld/Lq/ψf/p/Vdc/Imax`。
- 退出条件：输出全速域 `id/iq` 轨迹、转矩-转速曲线、电压裕度、铜耗、退磁边界。
- 淘汰条件：目标最高速下需要的负 `id` 超过退磁边界，或高速收益小于铜耗/效率损失。

## 3. 主线二：MTPA / FW / MTPV 连续控制

### 3.1 要验证的核心假设

可控磁通量的工程价值不在单个控制点，而在全速域轨迹：低速用 MTPA 降低电流，中高速进入弱磁维持电压边界，极高速用 MTPV 在电压受限条件下争取最大转矩。

### 3.2 控制区间定义

| 区间 | 主约束 | 控制目标 | 典型策略 |
|---|---|---|---|
| 低速恒转矩区 | 电流约束 | 同转矩最小电流 | MTPA |
| 中高速过渡区 | 电流 + 电压 | 满足电压同时尽量高效 | FW |
| 极高速电压极限区 | 电压约束 | 同电压最大转矩 | MTPV |

### 3.3 研发颗粒度

1. 建立电流圆搜索器：给定 `Imax` 和网格步长生成候选 `id/iq`。
2. 建立电压约束器：计算每个候选点在目标转速下的 `vd/vq/Vmag`。
3. 建立转矩约束器：筛选满足目标转矩的点，或找最大可用转矩。
4. 建立目标函数：
   - MTPA：同转矩最小电流；
   - FW：同转矩最大电压裕度或最小损耗；
   - MTPV：同电压最大转矩；
   - 效率优化：最小 `Pcu + Pfe + Pinv`。
5. 生成 LUT：
   - `id_ref(speed, torque, Vdc, T)`；
   - `iq_ref(speed, torque, Vdc, T)`；
   - `mode(speed, torque, Vdc, T)`。

### 3.4 切换和平滑要求

- MTPA 到 FW 不能出现转矩台阶。
- FW 到 MTPV 不能出现电压环积分饱和。
- `id_ref/iq_ref` 斜率需要限幅。
- Vdc 快速下跌时优先保护电压约束，而不是坚持转矩指令。
- 传感器误差或转速估计错误时，必须限制弱磁深度。

### 3.5 实验设计

| 实验 | 目标 | 输出 |
|---|---|---|
| CTRL-01 MTPA 基线 | 验证低速同转矩最小电流 | MTPA 曲线、转矩误差 |
| CTRL-02 FW 过渡 | 验证进入弱磁后的电压约束 | 模式切换点、`MarginV` |
| CTRL-03 MTPV 极限 | 验证高转速最大转矩边界 | MTPV 曲线、最大转矩 |
| CTRL-04 LUT 连续性 | 检查轨迹是否平滑 | `d(id)/dω`、`d(iq)/dω` |
| CTRL-05 Vdc 扰动 | 验证低母线保护 | 降转矩响应和电压不越限 |

## 4. 增强路线：SVPWM / 过调制 / 电压利用率提升

### 4.1 要验证的核心假设

在同样 `Vdc` 下，提高逆变器电压利用率可以推迟弱磁进入点，减少负 `id` 需求，从而降低弱磁铜耗。

### 4.2 关键边界

- 线性 SVPWM 区域电压利用率有限，但电流波形好。
- 过调制可提高电压输出能力，但会带来谐波和电流畸变。
- 六步波进一步提升电压，但 NVH、损耗和控制精度代价更高。

### 4.3 建模方式

在仿真中先抽象为 `Vmax_factor`：

```text
Vmax = Vdc / sqrt(3) * Vmax_factor
```

建议至少比较三档：

| 档位 | 含义 | 风险 |
|---|---|---|
| 1.00 | 保守线性调制 | 电压利用率较低 |
| 1.05-1.10 | 轻度过调制 | 谐波增加 |
| 1.10+ | 深度过调制/六步波接近 | NVH、损耗和控制风险高 |

### 4.4 判定逻辑

如果提高 `Vmax_factor` 能明显减少负 `id` 并提升工况加权效率，则进入控制实现评估；如果只提升最高速但导致损耗或 NVH 风险明显，则仅保留为极限工况策略。

## 5. 主线三：非线性磁链表

### 5.1 要验证的核心假设

真实电机在高电流下存在 d/q 轴饱和和交叉饱和，线性 `Ld/Lq` 无法准确预测转矩、电压边界和 MTPV 轨迹。引入 `λd/λq` 查表后，可以显著降低控制轨迹误差。

### 5.2 数据结构建议

```json
{
  "metadata": {
    "motor": "candidate_ipmsm_a",
    "temperature_c": [25, 80, 120],
    "source": "fem_or_bench"
  },
  "axes": {
    "id_a": [-400, -300, -200, -100, 0],
    "iq_a": [0, 100, 200, 300, 400]
  },
  "tables": {
    "lambda_d_wb": [],
    "lambda_q_wb": []
  }
}
```

### 5.3 插值和边界要求

- 插值方式先用双线性或样条，禁止无约束外推。
- 超出 LUT 边界时进入限幅或降额。
- LUT 需要温度维度，至少覆盖常温和高温。
- 转矩计算优先使用通用形式：

```text
Te = 1.5 * p * (iq * λd - id * λq)
```

### 5.4 验证指标

- 转矩误差：线性模型 vs LUT 模型。
- 电压边界误差：线性预测的 `MarginV` vs LUT 预测。
- MTPA/MTPV 轨迹偏差。
- 高电流区交叉饱和导致的 `Ld/Lq` 变化。
- 温度变化下的轨迹漂移。

## 6. 中期路线：磁路饱和协同设计

### 6.1 要验证的核心假设

通过转子磁桥、隔磁槽、磁钢布置和凸极比设计，让电机在不同电流角下表现出更有利的磁导变化，从而减少弱磁电流需求、改善 MTPV 高速区能力。

### 6.2 设计变量

- 转子拓扑：V 型、双 V、发卡形、PMaSynRM、低永磁占比 IPMSM。
- 磁桥厚度。
- 隔磁槽形状。
- 磁钢厚度和埋深。
- `Ld/Lq` 凸极比。
- `Ke` 和 `ψf`。
- 转矩脉动和齿槽转矩。
- 转子强度和最高机械转速。

### 6.3 FEA 扫描矩阵

| 维度 | 扫描目标 |
|---|---|
| `Ke` | 高速反电势压力 |
| `Ld/Lq` | 磁阻转矩和弱磁能力 |
| `ψf` | 低速永磁转矩贡献 |
| `λd/λq` 曲面 | 饱和和交叉饱和 |
| 转矩脉动 | NVH 风险 |
| 铁耗 | 高速效率 |
| 退磁裕度 | 高温和负 id 安全 |
| 转子应力 | 最高转速安全 |

### 6.4 决策逻辑

候选电机不能只按峰值转矩排序，应使用多目标评分：

```text
Score = w1 * weighted_efficiency
      + w2 * CPSR
      + w3 * torque_density
      - w4 * demag_risk
      - w5 * rotor_stress_risk
      - w6 * torque_ripple
```

权重由目标场景决定：高速巡航优先时提高效率和 CPSR 权重；重载起步优先时提高低速转矩密度权重。

### 6.5 淘汰门槛

- 退磁裕度不足的方案淘汰。
- 最高机械转速安全系数不足的方案淘汰。
- 高速铁耗过高且无法通过材料或几何修正的方案淘汰。
- MTPV 边界相比基线没有明显改善的方案降级。

## 7. 长期路线一：可变磁化状态 / Memory Motor

### 7.1 要验证的核心假设

通过磁化或去磁脉冲改变永磁体磁化状态，使 `ψf/Ke` 在多个档位之间切换。理论上它能同时兼顾低速大转矩和高速低反电势，但工程风险显著高于普通弱磁。

### 7.2 初期只做仿真的原因

- 需要特殊永磁材料和磁路设计。
- 磁化脉冲电流大，对逆变器和母线冲击高。
- 磁化状态不易直接观测。
- 高温和寿命循环下可能漂移。
- 错误磁化状态会带来转矩误差和安全风险。

### 7.3 仿真颗粒度

先抽象成多档 `ψf`：

```text
ψf_state ∈ {high, medium, low}
ψf = [ψf_high, ψf_mid, ψf_low]
Ke = f(ψf_state)
```

每个档位都重新计算：

- MTPA 曲线；
- FW 曲线；
- MTPV 曲线；
- 转矩-转速包络；
- 效率地图；
- 低速转矩损失；
- 高速反电势下降；
- 档位切换收益。

### 7.4 状态切换判据

只有当下面条件同时满足时，才考虑进入硬件预研：

- 低磁链档高速效率收益显著高于切换代价；
- 高磁链档仍能满足低速峰值转矩；
- 档位误判不会导致危险转矩输出；
- 状态观测或辨识方案可行；
- 高温保持和循环寿命有可验证路径。

### 7.5 必做故障分析

- 目标低磁链，实际高磁链：高速过压或电压饱和风险。
- 目标高磁链，实际低磁链：低速转矩不足。
- 磁化脉冲失败：状态不确定。
- 局部不可逆退磁：性能永久衰减。
- 传感器误差：状态估计漂移。

## 8. 长期路线二：混合励磁

### 8.1 要验证的核心假设

通过永磁体提供基础磁链，通过励磁绕组调节附加磁链，实现连续可调的等效磁通。

### 8.2 研发变量

- 励磁绕组布置。
- 励磁电流范围。
- 励磁时间常数。
- 励磁损耗。
- 热路径。
- 失励和过励保护。
- 与主 FOC 控制的耦合。

### 8.3 初期等效模型

```text
ψeff = ψPM + kf * if
Pfield = if^2 * Rfield
τfield = Lfield / Rfield
```

控制目标从二轴电流扩展为三变量：

```text
minimize Pcu(id,iq) + Pfield(if) + Pfe + Pinv
subject to Te_target, Vmax, Imax, thermal limits
```

### 8.4 关键判据

混合励磁只有在励磁损耗低于弱磁铜耗节省，且热管理可接受时才有意义。否则它只是把损耗从定子电流转移到励磁系统。

---

## 9. 长期路线三：绕组重构 / 多相控制

### 9.1 要验证的核心假设

通过改变绕组串并联、星三角连接，或多相电机的相组组合，改变等效匝数、`Ke/Kt` 或故障容错能力。

### 9.2 工程挑战

- 高压大电流切换器件成本高。
- 切换瞬态可能引起电流冲击和转矩冲击。
- EMI 和绝缘压力明显增加。
- 控制器需要管理多拓扑状态。
- 故障模式复杂，必须保证默认安全态。

### 9.3 初期建模方式

抽象为多个绕组配置：

```text
config ∈ {low_speed, high_speed}
Ke_config = [Ke_high, Ke_low]
Kt_config = [Kt_high, Kt_low]
Rs_config = [Rs_a, Rs_b]
Ls_config = [Ls_a, Ls_b]
```

比较每种配置下的：

- 低速峰值转矩；
- 高速电压裕度；
- 铜耗；
- 切换点；
- 切换前后转矩连续性；
- 故障默认状态。

### 9.4 判断标准

如果绕组重构只提升最高速，但引入过多开关和保护复杂度，应降级为远期探索；只有当它显著提升宽速域效率或提供明确容错价值时，才进入硬件方案。

---

## 10. 工况加权效率评估

### 10.1 为什么必须加入工况权重

可控磁通方案很容易在“最高速”指标上看起来有效，但实际车辆更关心常用工况效率和热负荷。必须建立工况权重，否则可能选出高成本但收益很小的方案。

### 10.2 建议工况集

| 工况 | 权重示例 | 关注点 |
|---|---:|---|
| 城市低速 | 20% | 低速效率、峰值转矩 |
| 中速巡航 | 25% | MTPA 效率 |
| 高速巡航 | 30% | 弱磁损耗、铁耗、逆变器损耗 |
| 加速超车 | 15% | 峰值功率和电压裕度 |
| 爬坡/高温 | 10% | 连续功率和热降额 |

### 10.3 指标输出

```text
ηweighted = Σ(wk * ηk)
Ploss_weighted = Σ(wk * Ploss_k)
Thermal_margin = Tmax_allowed - Tmax_predicted
```

所有路线最终都应放到同一张 Pareto 图中比较：

- 加权效率；
- CPSR；
- 峰值转矩；
- 成本/复杂度；
- 风险等级。

## 15. 当前建议

短期不要直接押注真实可变磁化、混合励磁或绕组重构。第一阶段的正确动作是把“普通 IPMSM 弱磁 + MTPA/FW/MTPV + 非线性磁链表”做到可仿真、可复现、可评分。

只有当仿真证明普通弱磁路线无法满足目标，或者长期路线在工况加权效率上有明确净收益时，才进入复杂硬件方案。这样可以避免在早期把风险推到材料、磁化脉冲、高压开关和台架安全上。

下一步建议 Codex 直接建立 `sim/`、`models/`、`experiments/` 和 `reports/`，从 Phase 1 线性 dq 闭环开始做最小可运行版本。
