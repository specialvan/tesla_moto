# 可控磁通量电机逐方案深度拆解

## 0. 读法和边界

本文不是再列一遍技术路线，而是把每种方案拆到可以被研发团队逐项验证的层级。每个方案都按同一套逻辑展开：

- 它到底改变了什么物理量；
- 它没有改变什么物理量，避免概念混淆；
- 它为什么能改善高速区；
- 它会把代价转移到哪里；
- 需要哪些模型和数据才能判断；
- 应该怎样设计实验；
- 什么结果说明它值得继续；
- 什么结果说明它应该停止。

一个核心原则必须先固定：**普通 IPMSM 弱磁控制只改变合成磁链和端电压需求，不改变永磁体本身的 `ψf/Ke`。** 真正改变等效 `ψf/Ke` 的路线主要是可变磁化状态、混合励磁、绕组重构或特殊多相/多绕组结构。

---

## 1. 总体物理框架

### 1.1 高速区真正卡住什么

PMSM/IPMSM 高速区通常不是先被转矩方程卡住，而是先被电压方程卡住：

```text
vd = Rs * id - ωe * λq
vq = Rs * iq + ωe * λd
Vmag = sqrt(vd^2 + vq^2)
Vmag <= Vmax
```

转速越高，`ωe * λd` 和 `ωe * λq` 越大。即使电流没有增加，端电压需求也会随速度上升。可控磁通量技术的第一目标，就是让高速区的 `λd/λq` 或等效电压矢量变小、变得更容易被母线电压覆盖。

### 1.2 三类“控磁通”不要混淆

| 类型 | 改变对象 | 代表方案 | 本质 |
|---|---|---|---|
| 控制型等效控磁 | 合成磁链、端电压矢量 | 负 d 轴弱磁、MTPV、过调制 | 不改变永磁体，靠电流矢量和电压利用率扩速 |
| 磁路型等效控磁 | 饱和磁导、`Ld/Lq`、磁通路径 | 高凸极 IPMSM、PMaSynRM、磁桥/隔磁槽优化 | 让电流更有效地改变磁链和转矩分配 |
| 真实可变磁链 | `ψf/Ke` 或等效匝数 | Memory Motor、混合励磁、绕组重构 | 直接改变反电势常数或永磁/励磁贡献 |

### 1.3 必须统一的评价指标

所有方案最终都要放到同一张评分表中比较：

```text
V_margin = Vmax - sqrt(vd^2 + vq^2)
I_margin = Imax - sqrt(id^2 + iq^2)
CPSR = ωmax / ωbase
Pcu = 3 * Irms^2 * Rs
ηweighted = Σ wk * ηk
Demag_margin = allowed_id_min(T, fault) - actual_id_min
```

不能只看“最高速更高”。如果最高速提升来自更大的负 `id`，但高速巡航铜耗和退磁风险明显增加，这不是好的控磁通方案。

## 2. 方案 A：负 d 轴弱磁

### 2.1 物理本质

线性模型下：

```text
λd = ψf + Ld * id
λq = Lq * iq
```

当 `id < 0` 时，`Ld * id` 为负，抵消一部分永磁磁链 `ψf`，从而降低 `vq` 中的 `ωe * λd` 项。高速区电压压力下降，电机可以继续维持转矩输出。

### 2.2 它改变什么

- 降低 d 轴合成磁链 `λd`。
- 改变电压矢量方向和幅值。
- 改变电流矢量角。
- 增加电流幅值和铜耗。
- 增加永磁体退磁风险。

### 2.3 它不改变什么

- 不改变永磁体本体磁化状态。
- 不改变空载反电势常数 `Ke`。
- 不改变电机绕组匝数。
- 不凭空降低损耗；它通常用更多电流换取电压裕度。

### 2.4 什么时候有效

负 d 轴弱磁有效的前提：

- `Ld` 足够大，负 `id` 对 `λd` 有明显抵消能力。
- 电流上限 `Imax` 还有余量。
- 退磁边界允许足够负的 `id`。
- 高速目标点不是被铁耗或机械强度先卡住。
- 母线电压在最低值时仍能提供一定余量。

### 2.5 什么时候失效

- `Ld` 太小，负 `id` 抵消磁链能力弱。
- `ψf` 太高，高速反电势过大。
- `Imax` 太低，负 `id` 挤占 `iq` 后转矩不足。
- 高温下磁钢退磁边界收紧。
- 低 Vdc 高转速下即使最大负 `id` 也越压。

### 2.6 研发变量

| 变量 | 作用 | 风险 |
|---|---|---|
| `Ld` | 决定弱磁效率 | 太大可能影响动态和设计空间 |
| `ψf` | 决定低速永磁转矩和高速反电势 | 太高高速难控，太低低速转矩不足 |
| `Imax` | 决定弱磁电流余量 | 受逆变器和热限制 |
| `id_min(T)` | 负 d 轴安全边界 | 高温退磁收紧 |
| `Vdc_min` | 最差电压工况 | 低电压下最容易失败 |

### 2.7 必做实验

| 实验 | 目的 | 关键输出 |
|---|---|---|
| `FW-A1` 负 id 扫描 | 找可行电流区域 | `id/iq/Vmag/Te/Pcu` |
| `FW-A2` 最高速边界 | 找目标转矩下最大速度 | `ωmax(target_torque)` |
| `FW-A3` 退磁边界 | 把 `id_min` 和温度挂钩 | `id_min(T)` |
| `FW-A4` 低母线测试 | 看最差 Vdc 下是否越压 | `V_margin(Vdc_min)` |
| `FW-A5` 工况效率 | 判断收益是否被铜耗抵消 | `ηweighted` |

### 2.8 淘汰门槛

满足任一条件就降级或停止：

- 目标最高速下 `id` 超过退磁安全边界。
- 弱磁后工况加权效率低于不弱磁基线。
- 低 Vdc 高速点无法保持正电压裕度。
- 负 `id` 导致 `iq` 不足，目标转矩无法达到。

## 3. 方案 B：MTPA / FW / MTPV 连续控制

### 3.1 物理本质

这不是单一技术，而是一套全速域电流轨迹策略：

- MTPA：低速区同转矩最小电流。
- FW：中高速区满足电压约束。
- MTPV：极高速电压受限时，同电压最大转矩。

它解决的是“电机在每个速度和转矩点应该站在哪个电流角上”。

### 3.2 MTPA 吃透

MTPA 的目标：

```text
minimize sqrt(id^2 + iq^2)
subject to Te(id, iq) = Ttarget
```

对 IPMSM，凸极性带来磁阻转矩：

```text
Te = 1.5 * p * [ψf * iq + (Ld - Lq) * id * iq]
```

如果 `Lq > Ld`，适当负 `id` 可以产生正磁阻转矩，让同样转矩需要更小电流。这就是为什么有些 IPMSM 在低速 MTPA 区也会使用负 `id`，不是只有高速弱磁才用负 `id`。

### 3.3 FW 吃透

FW 的目标不是最小电流，而是先活下来：

```text
sqrt(vd^2 + vq^2) <= Vmax
```

在电压快要越限时，控制器必须把 `id` 往负方向推，降低 `λd`。此时效率目标要让位给电压约束。

### 3.4 MTPV 吃透

MTPV 的目标：

```text
maximize Te(id, iq)
subject to Vmag(id, iq, ω) <= Vmax
           Imag(id, iq) <= Imax
```

极高速时电压椭圆比电流圆更硬。MTPV 会选择让每一伏电压产生最大转矩的电流角。这个点不一定电流最小，也不一定铜耗最低。

### 3.5 关键工程问题

- MTPA/FW/MTPV 切换不能有转矩台阶。
- 电压环不能积分饱和。
- `id_ref/iq_ref` 需要限斜率。
- LUT 需要随 `Vdc` 和温度变化。
- 轨迹必须有不可行点标记，不能硬插值出不存在的点。

### 3.6 研发交付物

| 交付物 | 内容 |
|---|---|
| `control_lut.json` | `speed/torque/Vdc/T -> id/iq/mode` |
| `trajectory_continuity_report.md` | 切换点斜率、转矩台阶、电压裕度 |
| `infeasible_region_map.csv` | 哪些工况不能满足目标 |
| `derating_policy.md` | 不可行时降转矩、降速或限功率策略 |

### 3.7 淘汰门槛

MTPA/FW/MTPV 本身不会被淘汰，但某个轨迹版本会被淘汰：

- 切换点转矩台阶超过允许值。
- Vdc 突降时越压。
- 高速区电流振荡或轨迹不连续。
- LUT 外推导致不可控指令。

## 4. 方案 C：SVPWM / 过调制 / 六步波电压利用率提升

### 4.1 物理本质

这个方案不改变电机本体，而是提高逆变器从同一 `Vdc` 中能输出的基波电压。电压约束变宽，弱磁进入点推迟。

抽象模型：

```text
Vmax = Vdc / sqrt(3) * k_mod
```

`k_mod` 越高，高速电压裕度越大。

### 4.2 它解决什么

- 推迟弱磁进入速度。
- 减少同一高速点所需负 `id`。
- 减少弱磁铜耗。
- 提升母线利用率。

### 4.3 它引入什么

- 电流谐波。
- 转矩脉动。
- NVH 风险。
- 逆变器开关损耗和导通损耗变化。
- 电流采样和控制线性度问题。

### 4.4 三档策略

| 档位 | 用途 | 适用边界 |
|---|---|---|
| 线性 SVPWM | 常规运行 | 效率、NVH、控制精度优先 |
| 轻度过调制 | 高速扩展 | 短时或高负载过渡 |
| 深度过调制/六步波 | 极限扩速 | 必须单独验证 NVH、热和电流畸变 |

### 4.5 必做实验

| 实验 | 输出 |
|---|---|
| `MOD-C1` `k_mod` 扫描 | 弱磁进入点、负 `id` 需求 |
| `MOD-C2` 谐波损耗估算 | 电流 THD、附加铜耗/铁耗 |
| `MOD-C3` 转矩脉动 | 转矩 ripple vs 调制档位 |
| `MOD-C4` 电流环稳定性 | 过调制下电流跟踪误差 |

### 4.6 判断标准

如果轻度过调制能显著降低负 `id`，且谐波和 NVH 可控，它是很划算的增强策略。如果收益只体现在极限最高速，而常用工况效率没有改善，应只作为短时极限模式。

## 5. 方案 D：非线性磁链表 `λd/λq LUT`

### 5.1 物理本质

真实电机不是固定 `Ld/Lq`。高电流下会出现：

- d 轴饱和；
- q 轴饱和；
- 交叉饱和；
- 温度影响；
- 局部磁桥饱和；
- 磁钢工作点变化。

所以磁链应从常数电感模型升级为：

```text
λd = f(id, iq, T)
λq = f(id, iq, T)
Te = 1.5 * p * (λd * iq - λq * id)
```

### 5.2 它改变研发方式

没有 LUT 时，控制器相信线性模型；有 LUT 后，控制器相信实际磁链曲面。MTPA、FW、MTPV 都应该重新求解。

### 5.3 LUT 必须包含什么

| 字段 | 说明 |
|---|---|
| `id_axis_a` | d 轴电流网格 |
| `iq_axis_a` | q 轴电流网格 |
| `temperature_axis_c` | 温度网格 |
| `lambda_d_wb` | d 轴磁链表 |
| `lambda_q_wb` | q 轴磁链表 |
| `source` | FEA、台架、混合拟合 |
| `unit_convention` | 峰值/RMS、dq 变换约定 |
| `valid_bounds` | 禁止外推的有效边界 |

### 5.4 数据来源分层

| 阶段 | 数据来源 | 用途 |
|---|---|---|
| 初期 | 人造物理合理 LUT | 验证接口和算法 |
| 中期 | FEA 扫描 | 生成候选拓扑控制轨迹 |
| 后期 | 台架辨识 | 修正真实电机控制 LUT |

### 5.5 常见坑

- 继续用线性转矩公式，导致 LUT 白做。
- LUT 外推到未验证高电流区。
- 没有温度维度。
- FEA 数据和控制器 dq 坐标定义不一致。
- 峰值电流和 RMS 电流混用。
- 插值后破坏物理单调性。

### 5.6 必做实验

| 实验 | 判定 |
|---|---|
| `LUT-D1` 线性 vs LUT 转矩误差 | LUT 高电流区误差更小 |
| `LUT-D2` MTPA 轨迹重算 | 轨迹连续且低电流 |
| `LUT-D3` MTPV 边界重算 | 高速边界不乐观 |
| `LUT-D4` 温度漂移 | 高温下轨迹安全收敛 |
| `LUT-D5` 边界裁剪 | 超出 LUT 不产生危险指令 |

### 5.7 判断标准

非线性磁链表是从研究走向工程必须跨过的一关。它不是“增益可选项”，而是让后续电磁设计、控制标定和台架回灌能够闭环的核心数据结构。

## 6. 方案 E：磁路饱和协同设计

### 6.1 物理本质

通过转子几何和磁路设计，让不同电流角下的磁导变化更有利。它不是让控制器“更聪明”，而是让电机本体对控制指令更敏感。

重点变量：

```text
Ld(id, iq), Lq(id, iq), λd(id, iq), λq(id, iq)
```

### 6.2 可调几何

- 磁桥厚度。
- 隔磁槽形状。
- V 型磁钢夹角。
- 双 V 或多层磁钢。
- PMaSynRM 永磁占比。
- 转子 rib 和 web 尺寸。
- 气隙长度。
- 定子槽极配合。
- 磁钢牌号和厚度。

### 6.3 想要的电磁特征

- 低速区足够 `ψf` 和转矩密度。
- 中高速区 `Ld/Lq` 让磁阻转矩可用。
- 负 `id` 对 `λd` 抵消效率高。
- MTPV 区电压边界友好。
- 转矩脉动不过大。
- 高速铁耗不过高。
- 转子强度足够。
- 退磁裕度足够。

### 6.4 FEA 扫描方法

每个候选拓扑都至少输出：

```text
Ke
Ld/Lq small signal
λd(id, iq)
λq(id, iq)
torque map
torque ripple
iron loss map
demag margin
rotor stress margin
```

然后把 FEA 输出喂回控制搜索，不能只看静态电磁指标。

### 6.5 决策表

| 现象 | 解释 | 动作 |
|---|---|---|
| `Ke` 低但低速转矩不足 | 永磁贡献过低 | 增加磁钢或提高电流能力 |
| 凸极比高但脉动大 | 磁阻转矩带来 ripple | 优化槽极/转子形状 |
| 弱磁好但铁耗高 | 高速磁通谐波或材料损耗 | 调整材料和磁路 |
| MTPV 好但强度不足 | 转子几何太激进 | 加强机械设计或降最高速 |
| 退磁裕度不足 | 磁钢工作点危险 | 换牌号/厚度/保护边界 |

### 6.6 淘汰门槛

- 转子应力不满足最高速安全系数。
- 高温最大负 `id` 下退磁不可接受。
- 高速铁耗导致热模型不可收敛。
- FEA 生成的 LUT 不能支持目标工况。

## 7. 方案 F：PMaSynRM / 高凸极低永磁占比路线

### 7.1 物理本质

PMaSynRM 用较少永磁体辅助同步磁阻电机。它把一部分转矩来源从永磁转矩转移到磁阻转矩：

```text
Te = Tpm + Treluctance
Tpm = 1.5 * p * ψf * iq
Treluctance = 1.5 * p * (Ld - Lq) * id * iq
```

如果永磁占比降低，`Ke` 压力下降；如果凸极性足够，仍能靠磁阻转矩补足一部分转矩。

### 7.2 优点

- 高速反电势压力低。
- 永磁材料成本可能降低。
- 弱磁能力通常更好。
- 高速 CPSR 潜力较大。

### 7.3 代价

- 控制更依赖电流角。
- 低速峰值转矩可能下降。
- 转矩脉动和 NVH 更敏感。
- 转子结构更复杂。
- 对 FEA 和 LUT 依赖更高。

### 7.4 关键问题

PMaSynRM 的成败不是“永磁少”，而是少永磁后是否还能通过 `Ld/Lq` 和电流能力维持目标转矩。如果磁阻转矩补不上，低 Ke 只会变成低性能。

### 7.5 必做实验

- 永磁占比扫描。
- `Ld/Lq` 凸极比扫描。
- 同电流限制下转矩-转速包络。
- 高速铁耗对比。
- 转矩脉动对比。
- 退磁裕度对比。

### 7.6 进入下一阶段条件

- 相比常规 IPMSM，高速弱磁铜耗下降。
- 目标低速峰值转矩仍可满足。
- 转矩脉动可通过几何优化压住。
- 转子强度不成为硬失败项。

## 8. 方案 G：可变磁化状态 / Memory Motor

### 8.1 物理本质

可变磁化状态方案试图改变永磁体磁化水平，使 `ψf` 变成状态变量：

```text
ψf ∈ {ψhigh, ψmid, ψlow}
Ke ∝ ψf
```

低速用高磁链，高速切到低磁链。它是真正接近“可变磁通量”的路线。

### 8.2 它为什么诱人

普通弱磁用负 `id` 抵消磁链，会持续消耗铜耗。Memory Motor 如果能把 `ψf` 本身降下来，高速区可能少用负 `id`，从根上降低端电压需求。

### 8.3 它为什么危险

- 磁化/去磁脉冲电流大。
- 对逆变器和母线冲击大。
- 磁化状态不是普通传感器能直接看到的。
- 高温下状态可能漂移。
- 局部不可逆退磁会造成永久性能下降。
- 状态错判会导致转矩和电压预测错误。

### 8.4 初期建模

不要一开始建复杂材料模型。先做多档 `ψf` 等效模型：

```text
state = high/mid/low
ψf_state = [0.055, 0.040, 0.025] Wb
```

每个状态重新跑：

- MTPA；
- FW；
- MTPV；
- 转矩-转速；
- 效率地图；
- 低速峰值转矩；
- 高速电压裕度；
- 切换收益阈值。

### 8.5 再往下才考虑的模型

- 磁化曲线。
- 磁滞回线。
- 磁化脉冲能量。
- 状态保持时间。
- 温度漂移。
- 循环寿命。
- 局部退磁空间分布。

### 8.6 状态观测思路

可考虑但不能一开始承诺：

- 高频注入估计磁链状态。
- 空载或轻载反电势估计。
- 在线参数辨识。
- 电压模型反推 `ψf`。
- 扭矩误差闭环估计。

这些方法都有速度、电流、温度和噪声边界，必须单独验证。

### 8.7 必做故障表

| 指令状态 | 实际状态 | 风险 |
|---|---|---|
| 低磁链 | 高磁链 | 高速过压、电压饱和 |
| 高磁链 | 低磁链 | 低速转矩不足 |
| 中磁链 | 局部退磁 | 转矩脉动、效率下降 |
| 任意 | 状态未知 | 必须降级到保守控制 |

### 8.8 硬件进入门槛

只有同时满足以下条件才值得硬件预研：

- 仿真显示工况加权效率显著高于普通弱磁。
- 高磁链状态满足低速峰值转矩。
- 低磁链状态明显降低高速电压压力。
- 状态观测方案有可验证路径。
- 磁化脉冲能量和器件应力可接受。
- 失效后有安全降级模式。

---

## 9. 方案 H：混合励磁

### 9.1 物理本质

混合励磁让永磁磁链和励磁绕组磁链叠加：

```text
ψeff = ψPM + kf * if
```

如果 `if` 可正可负，就可以增强或削弱等效磁链。它比 Memory Motor 更连续，但引入励磁损耗和结构复杂度。

### 9.2 它能解决什么

- 连续调节磁链。
- 高速弱磁时减少负 d 轴电流需求。
- 低速时可增强磁链。
- 理论上可做更柔和的全域效率优化。

### 9.3 它把代价转移到哪里

- 励磁铜耗 `Pfield = if^2 * Rfield`。
- 励磁绕组热管理。
- 励磁电源或功率通道。
- 结构空间。
- 失励/过励故障保护。
- 控制维度从 `id/iq` 扩展到 `id/iq/if`。

### 9.4 优化目标

不能只看主绕组铜耗，应看总损耗：

```text
minimize Pcu(id, iq) + Pfield(if) + Pfe + Pinv
subject to Te_target
           Vmag <= Vmax
           I_main <= Imax
           I_field <= Ifmax
           thermal_limits
```

### 9.5 关键判据

混合励磁值得做的唯一理由，是励磁带来的弱磁铜耗节省和效率收益大于励磁系统自身代价。如果只是把定子铜耗换成励磁铜耗，同时增加结构复杂度，就不值得。

### 9.6 必做实验

| 实验 | 输出 |
|---|---|
| `HE-H1` `if` 扫描 | `ψeff/Ke/Vmargin` |
| `HE-H2` 总损耗对比 | `Pcu + Pfield + Pfe + Pinv` |
| `HE-H3` 热模型 | 励磁绕组温升 |
| `HE-H4` 失励故障 | 转矩和电压响应 |
| `HE-H5` 控制耦合 | `id/iq/if` 轨迹稳定性 |

### 9.7 淘汰门槛

- 励磁损耗大于节省的弱磁损耗。
- 励磁热路径不可接受。
- 失励导致不可控转矩或过压。
- 包络和成本不允许。

---

## 10. 方案 I：绕组重构

### 10.1 物理本质

绕组重构通过改变串并联、星三角、抽头或多套绕组连接方式，改变等效匝数：

```text
Ke ∝ N
Kt ∝ N
R ∝ N relation by connection
L ∝ N^2 relation by connection
```

低速用高匝数获得高 `Kt`，高速用低匝数降低 `Ke`。

### 10.2 它为什么有吸引力

它直接改变 `Ke/Kt`，不是靠负 `id` 抵消。理论上可以让高速区端电压压力显著下降。

### 10.3 它为什么难

- 高压大电流切换器件难。
- 切换瞬态会产生电流和转矩冲击。
- 开关网络增加损耗和故障点。
- EMI 和绝缘压力变大。
- 切换时机必须和电流、电压、转速同步。
- 故障安全态很难设计。

### 10.4 建模方式

先抽象为两个或三个配置：

```text
config = low_speed / mid_speed / high_speed
Ke(config)
Kt(config)
Rs(config)
Ld(config)
Lq(config)
Imax(config)
Vlimit(config)
```

每个配置独立跑 MTPA/FW/MTPV，再设计切换点。

### 10.5 切换点选择

理想切换点必须满足：

- 切换前后目标转矩都可达。
- 电压裕度都为正。
- 电流幅值不过限。
- 转矩差足够小。
- 切换损耗和冲击可接受。

### 10.6 必做实验

| 实验 | 目的 |
|---|---|
| `WR-I1` 多配置包络 | 比较各配置转矩-转速 |
| `WR-I2` 切换点扫描 | 找最小转矩台阶点 |
| `WR-I3` 瞬态仿真 | 评估电流冲击 |
| `WR-I4` 故障态分析 | 开关卡滞、开路、短路 |
| `WR-I5` EMI/绝缘预评估 | 判断硬件复杂度 |

### 10.7 判断标准

如果绕组重构只带来最高速提升，却需要复杂高压开关网络，不适合早期投入。只有当它在宽速域效率、低速/高速兼顾或容错性上有明确大收益，才值得进入硬件预研。

---

## 11. 方案 J：多相电机 / 相组控制

### 11.1 物理本质

多相电机通过更多相数或多套相组，提供更高控制自由度。它可以用于：

- 容错运行；
- 谐波电流注入；
- 多子空间转矩控制；
- 相组重构；
- 降低单相电流压力。

它不是天然控磁通方案，但可以配合绕组重构、谐波注入或容错控制形成扩展路线。

### 11.2 可能收益

- 故障后仍能输出转矩。
- 电流分配更灵活。
- 可利用谐波子空间改善转矩或抑制 ripple。
- 相组切换可能改变等效磁场。

### 11.3 代价

- 逆变器相数增加。
- 控制算法复杂。
- 参数辨识复杂。
- 保护逻辑复杂。
- 成本和体积上升。

### 11.4 早期判断

多相方案不应作为第一阶段主线，除非目标需求明确包含高容错或极高功率密度。否则它会过早放大系统复杂度。

---

## 12. 方案 K：温度、退磁和安全保护

### 12.1 为什么它是单独方案

可控磁通量方案越激进，越依赖负 `id`、高电流、高速电压边界和磁钢工作点。没有温度和退磁保护，前面的控制策略都不能进入实机。

### 12.2 必须建模的温度影响

- `Rs(T)` 上升，铜耗和电压降变化。
- `ψf(T)` 下降，转矩和反电势变化。
- 磁钢矫顽力下降，退磁风险上升。
- 铁耗随温度和频率变化。
- 逆变器热限制影响 `Imax`。

### 12.3 退磁边界

控制器需要温度相关的负 d 轴限制：

```text
id >= id_min(Tmag, speed, fault_margin)
```

这个边界不能由控制团队拍脑袋给出，必须来自磁钢退磁曲线、FEA 或台架验证。

### 12.4 故障工况

必须覆盖：

- 低 Vdc + 高转速。
- 高温 + 最大负 `id`。
- 短路。
- 过流。
- 传感器角度误差。
- 速度估计错误。
- 再生时电池拒充。
- 负载突卸。

### 12.5 保护优先级

```text
硬件保护 > 退磁保护 > 电压限制 > 电流限制 > 热限制 > 转矩跟随 > 效率优化
```

MTPA/FW/MTPV 是优化策略，不是安全策略。

---

## 13. 方案 L：工况加权效率和 Pareto 选择

### 13.1 为什么它决定最终路线

所有控磁通方案都可能在某个点表现很好。研发决策需要回答的是：真实使用工况下，它是否净收益更高。

### 13.2 工况权重

建议至少定义：

- 城市低速；
- 中速巡航；
- 高速巡航；
- 加速超车；
- 长坡高温；
- 低温低电压；
- 高速再生。

### 13.3 Pareto 维度

| 维度 | 越高越好/越低越好 |
|---|---|
| 加权效率 | 高 |
| CPSR | 高 |
| 峰值转矩 | 高 |
| 连续功率 | 高 |
| 退磁风险 | 低 |
| 热风险 | 低 |
| 控制复杂度 | 低 |
| 硬件复杂度 | 低 |
| 成本 | 低 |

### 13.4 决策逻辑

短期选择不应该追逐最高理论上限，而应选择“收益明确、验证路径短、失败代价低”的路线。按这个标准：

1. 普通 IPMSM/PMaSynRM + MTPA/FW/MTPV + LUT 是主线。
2. 过调制和磁路协同是增强线。
3. 可变磁化、混合励磁、绕组重构是预研线。

## 14. 每种方案的下一步证伪实验

| 方案 | 最小证伪实验 | 若失败说明 |
|---|---|---|
| 负 d 轴弱磁 | 目标转矩-速度下扫描 `id/iq/Vdc_min/Tmax` | 电流或退磁边界不够 |
| MTPA/FW/MTPV | 生成全速域 LUT 并检查连续性 | 控制轨迹不可标定 |
| 过调制 | 扫描 `k_mod` 对负 `id` 和损耗影响 | 电压利用率收益不够 |
| 非线性 LUT | 用 LUT 重算轨迹并比较线性误差 | 线性模型误导严重或 LUT 质量不足 |
| 磁路协同 | FEA 输出 `λd/λq` 后回灌控制 | 几何没有带来控制收益 |
| PMaSynRM | 永磁占比和凸极比扫描 | 低 Ke 牺牲了太多低速转矩 |
| Memory Motor | 多档 `ψf` 效率地图 | 真实变磁收益不足 |
| 混合励磁 | `Pfield` vs 弱磁铜耗节省 | 励磁损耗不划算 |
| 绕组重构 | 多配置包络和切换点扫描 | 切换复杂度不值 |
| 多相控制 | 容错或谐波收益评估 | 复杂度没有明确收益 |

## 15. 研发优先级重排

### 第一优先级：必须做

- 线性 dq 全速域扫描。
- MTPA/FW/MTPV 搜索。
- 电压裕度和电流裕度输出。
- 铜耗和温度敏感性。
- `λd/λq` LUT schema。
- 不可行工况标记。

### 第二优先级：尽快做

- 非线性 LUT 接口。
- 工况加权效率。
- 退磁边界简化模型。
- Vdc_min 扰动。
- `k_mod` 调制因子扫描。

### 第三优先级：中期做

- FEA 候选拓扑。
- 磁路饱和协同评分。
- PMaSynRM 对比。
- 高速铁耗模型。
- 热降额模型。

### 第四优先级：预研做

- 可变 `ψf` 多档模型。
- 混合励磁等效模型。
- 绕组重构多配置模型。
- 多相/相组控制收益边界。

---

## 16. 总结判断

可控磁通量电机不是单一黑科技，而是一组围绕高速电压约束展开的技术包。真正要吃透每种方案，需要把它们放回同一套电压、电流、磁链、损耗、温度和安全边界里比较。

当前最稳的研发路径是：

```text
先用线性 dq 找理论边界
再用非线性 λd/λq LUT 修正边界
再用 FEA 设计更适合弱磁和 MTPV 的磁路
再用工况加权效率筛选候选
最后才判断是否值得进入真实可变磁链硬件
```

短期不要把“可控磁通量”理解成必须立即做 Memory Motor 或混合励磁。普通 IPMSM/PMaSynRM 的控制型等效控磁，是低风险主线；真实可变磁链是高风险预研线。两者应并行建模，但不能混成同一个成熟度等级。
