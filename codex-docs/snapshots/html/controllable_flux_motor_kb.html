1. 目标定义

不依赖闭源资料，不推测任何厂商实现。以干净室方式从 dq 方程、电磁有限元、控制优化和台架数据出发，构建“等效控磁通”技术体系。

低速

高磁链 / 高转矩

保持峰值转矩、起步能力和中低速效率。

高速

低合成磁链 / 低端电压需求

普通弱磁降低合成 d 轴磁链和端电压压力；只有可变磁化、混合励磁或绕组重构才改变等效 Ke/ψf。

全域

效率地图最优

按工况权重优化电机 + 逆变器系统效率，而不是单点峰值。

安全

退磁、过压和电压饱和保护

区分低 Vdc 高转速下的电压饱和风险，以及再生/负载突卸下的母线过压风险。

2. 核心物理方程

dq 电压模型

完整动态：
vd = Rs·id + dλd/dt - ωe·λq
vq = Rs·iq + dλq/dt + ωe·λd

准稳态扫描：
vd ≈ Rs·id - ωe·λq
vq ≈ Rs·iq + ωe·λd

转矩-转速和 MTPV 边界先用准稳态模型；电流环、切换和故障仿真必须使用动态模型。

磁链模型

线性：λd = Ld·id + ψf，λq = Lq·iq
非线性：λd=LUTd(id,iq,T)，λq=LUTq(id,iq,T)

LUT 必须约定单位、温度维度、插值方式和边界裁剪，禁止无保护外推。

转矩模型

线性：Te = 1.5·p·[ψf·iq + (Ld-Lq)·id·iq]
非线性：Te = 1.5·p·(λd·iq - λq·id)

单位与约束

sqrt(vd²+vq²) ≤ Vmax
sqrt(id²+iq²) ≤ Imax
ωe = p·ωm

首版统一采用幅值不变 dq、相电压峰值、相电流峰值、单相 Rs；SVPWM 下 Vmax 由 Vdc 换算。

8. 风险边界与判断标准

V 裕度Vmax - sqrt(vd²+vq²)，高速控制核心指标。
I 裕度Imax - sqrt(id²+iq²)，决定弱磁和转矩能力。
Ke 降低低磁链状态下反电势常数下降比例。
CPSR最高速 / 基速，衡量恒功率扩展能力。
加权效率按真实工况权重汇总效率，而非只看峰值。
退磁裕度高温 + 负 id + 短路工况下必须安全。
干净室研发原则：不复刻闭源方案；所有结论必须来自公开模型、开源工具、仿真数据或台架实验。AI/Codex 输出只作为研发草案，不能直接部署到高压高速实机，必须经过人工审查、仿真、HIL/台架和硬件保护验证。
