1. V2 推进策略

V2 不把所有路线都推向硬件，而是给每条路线明确：是否进入近期主线、输入模型和输出接口、BOM/EDA 影响、缺失验证证据、进入下一门或停止推进条件。

总纪律：主线先闭环，候选靠 scorecard 晋级，研究池靠 guardrail 防止误判。

3. 主线四件套

P0

负 d 轴弱磁

必补 id_min(T,fault)、油冷边界、Vdc_min、传感器可信度；输出 voltage/current/demag/thermal margin。

P0

MTPA/FW/MTPV

必补二维速度-转矩 LUT、mode transition、CRC、generator metadata；输出发布型 control LUT。

P0

非线性磁链 LUT

必补单位、坐标、峰值/RMS、温度维度、candidate ID；输出 LUT 模式控制轨迹和越界原因。

P0

安全保护

必补磁钢温度、油温、sensor fault、gate-disable、fault latch；任何方案不能证明故障安全，不允许进硬件门。

4. 中期候选

SVPWM / 过调制

高速区附加模式；必须证明 THD/NVH、逆变器损耗、启停窗口和退出条件可控。

磁路饱和协同

必须走候选几何 → FEA LUT → 控制评分，不允许只靠参数缩放晋级。

PMaSynRM

必须证明低 PM 成本收益不牺牲主工况效率、峰值转矩、ripple、stress 和 demag 安全。

Pareto 决策

所有路线统一出口；必须区分 research rank 与 engineering recommendation。

5. 研究池 Guardrail

方案禁止误判必补证据
Memory Motor不能用 psi_f 缩放代表工程可行性磁状态机、脉冲能量、状态观测、未知状态回退、寿命
混合励磁不能只看 psi_eff = psi_pm + kf * if三变量优化、field converter 损耗、field thermal、loss-of-field
绕组重构不能只看静态 Ke/Kt 缩放切换瞬态、环流、arc、interlock、open/short/stuck fault
多相相组不能只用可用电流降额代理fault torque allocator、harmonic subspace、资源预算、容错需求

6. 近期执行顺序

  1. 主线四件套闭环：弱磁 + 控制 LUT + 非线性 LUT + 安全保护。
  2. 候选 scorecard：FEA LUT、扁线、油冷、系统损耗、NVH、制造风险。
  3. 研究池 guardrail：Memory Motor、混合励磁、绕组重构、多相全部设停/进条件。
