V2 PRD：review-pr 工程落地差距

基于可变磁通、扁线、油冷、多合一两篇外部资料，逐条对齐当前可控磁通研究主线与真实量产电驱工程之间的差距。本文是摘要阅读版，完整需求以同目录 Markdown PRD 为准。

总判断 条目化映射 功能需求 阶段门 优先级 维护规则

1. V2 总判断

继承主线

v0.3 控制骨架继续有效

弱磁、MTPA/FW/MTPV、非线性磁链 LUT、热/退磁安全保护仍是近期最现实的工程主线。

研究池重点

可变磁通必须变成状态机问题

不能把 psi_f 档位缩放实验误写成 Memory Motor 工程可行性证明。

硬件阶段门

扁线、油冷、多合一必须入门

真实工程放行依赖绕组、冷却、BOM/EDA、DFMEA、DVP&R、台架和 PV 证据。

核心结论：V2 不是继续横向增加实验，而是把控制主线、磁状态研究池和系统工程阶段门拉到同一条证据链上。

2. review-pr 条目化映射

资料 A：可变磁通 / 电磁调磁

条目外部资料主张当前状态V2 要求
A-1电磁脉冲改变等效磁通仅有静态 psi_f 档位增加磁化/去磁脉冲能量、电流、电压、时间
A-2低速高磁链、高速低磁链弱磁与变量磁链实验分离区分负 id 弱磁和真实磁状态改变
A-3磁状态需要保持和重复切换无保持、漂移、寿命模型定义保持时间、漂移、重复切换寿命
A-4无机械调磁但控制更复杂无状态机和回退策略定义磁状态机、禁止区、fallback state
A-5高速收益受退磁和电压裕度约束只有简化 demag limit将磁状态、温度、Vdc、退磁统一进入 LUT 过滤
A-6工程价值取决于可控可观测可保护只有数值假设禁止把 psi_f 缩放实验写成工程可行性证明

资料 B：扁线 / 油冷 / 多合一

条目外部资料主张当前状态V2 要求
B-1扁线提升槽满率和功率密度电机参数无绕组几何增加绕组类型、槽满率、导体截面、端部长度
B-2扁线带来 AC 铜耗、制造和 NVH 风险损耗模型仍简化scorecard 加入 AC 铜耗、制造风险、NVH 风险
B-3油冷支撑高热流密度只有简化温度模型增加油温、流量、压力、喷油/甩油路径
B-4磁钢温度约束退磁边界id_min(T) 来源简化demag curve 必须追溯材料、FEA 或台架数据
B-5多合一集成耦合热、EMC、NVH、服务性BOM/EDA 只有目录级规划输出页级 BOM/EDA、接口、接地、连接器和冷却约束
B-6量产放行依赖硬证据仓库主要是数值仿真numeric simulation 不能替代 G4-G7 证据
B-7高效率要看系统损耗未覆盖逆变器/机械/油泵/冷却惩罚Pareto 增加 system loss breakdown

3. V2 功能需求

FR-1 磁状态机

flux_state_id、脉冲能量、观测可信度、fallback state、不可逆退磁风险。

FR-2 扁线绕组输入

绕组类型、槽满率、导体截面、端部长度、AC/DC 铜耗和制造风险。

FR-3 油冷热边界

油温、流量、压力、定子/转子/磁钢温度、demag curve 来源。

FR-4 多合一 BOM/EDA

gate driver、sensing、DC-link、oil pump、fault latch、HV/LV connector 页面。

FR-5 系统损耗 Pareto

铜耗、铁耗、逆变器、机械、油泵、冷却惩罚、复杂度和成熟度评分。

4. 阶段门更新

阶段门V2 新增要求
G0-G1目标车型、冷却架构、是否允许磁状态切换、安全目标和故障回退。
G2机械调磁 vs 电磁调磁、扁线 vs 圆线、水套 vs 油冷、多合一接口 trade study。
G3FEA/实测到 LUT、油冷热边界、系统损耗、磁状态机、控制 LUT 统一表达。
G4页级 BOM/EDA、油泵/压力/温度 sensing、gate-disable、DFMEA。
G5-G6油冷覆盖率、热循环、NVH/EMC、重复切换寿命、故障注入。
G7PV/PPAP/release/change-control 证据，不得由数值仿真替代。

5. 下一步优先级

P0

立即补入主线

模型来源、安全边界来源、不可行原因、热/退磁边界、阶段门硬证据声明。

P1

实现前置需求

FEA/实测 LUT 输入规范、候选 scorecard、系统损耗 Pareto、页级 BOM/EDA。

P2

研究池规范

Memory Motor 状态机、磁化/去磁脉冲、状态观测、未知状态回退、调磁 trade-off。

6. 维护规则

  1. V2 PRD 是完整需求源，Wiki 是知识库索引版，HTML 是评审阅读版。
  2. 更新任一版本时，应同步更新 wiki、HTML、快照、manifest 和证据说明。
  3. 当前数值实验默认不得越过 numeric_simulation 成熟度。
最终判断：v0.3 控制主线继续推进；可变磁通必须先变成状态机和安全问题；扁线、油冷、多合一必须进入系统工程阶段门。
