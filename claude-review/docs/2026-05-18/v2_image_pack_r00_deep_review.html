4. r01 推进决策

D-01 P0 必修 8 张

覆盖 4 个 T03 状态机语义错、3 个 T05 BLOCKER、1 个 T04 密度过高。

D-02 P1 建议修 40 张

主要修 T02 sequence 和 T05 写实化弱化。

D-03 P2 可保留 48 张

已具备评审锚点能力，不需要立即重生。

D-04 / D-05 提示词升级

扩展全局正向（hex 颜色 + 标题强制）与负向（材料牌号 + 写实化禁用）。

D-06 显式枚举

T03 / T07 prompt 列出 STATES / EDGES / DVP IDs，禁止追加。

D-07 尺寸覆盖

schemes.json 落实 T01 1792×1024、T04 1024×1280、T05 1280×1024 等。

r01 prompt 全文落在 codex-review/docs/scheme_drawing_prompt_catalog_2026-05-18_r01.md，含模板级与方案级双层。

5. 禁止误读

  • 本评审判定的是 生图与提示词的对齐度，不是图与真实工程交付物的等价。
  • r00 / r01 PNG 都 不替代 PCB / EDA / CAD / FEA / HIL 任何文件。
  • r01 重生后若仍出现真实牌号或写实 render，必须立即拒收。
  • 任何方案语义改动必须先回到 engineering/v2/scheme-XX/ 的 .drawio / mermaid / markdown 源。
