# V2 高速反电动势待定方案深度梳理暂存

## 1. 暂存目的

本文件沉淀本轮关于高速反电动势、弱磁电耗、混合励磁、物理换挡、绕组重构、可调磁通与 FE 方程式赛车策略的讨论结论。当前内容属于**待定方案 / 深度梳理暂存**，用于后续仿真、工程审查和 handoff，不作为工程验证结论。

核心问题：固定磁链 IPMSM 在高速区会遇到 `E ≈ Ke × ω` 的反电动势压力。若长期依赖负 d 轴弱磁，可能显著增加定子电流、铜耗、逆变器损耗和热压力。下一阶段需要判断哪些路线能真正降低全工况总损耗，而不是把损耗从一个子系统转移到另一个子系统。

## 2. 第一性原理判断

### 2.1 高速反电动势根因

```text
E ≈ Ke × ωmotor
Vmax ≈ Vdc / sqrt(3)
```

当 `E` 接近逆变器可用相电压上限时，控制器必须通过弱磁、降扭、提高母线电压、降低电机转速或降低等效 `Ke/ψf` 来保持可控。

低速与高速的天然矛盾：

```text
高 Ke / 高 Kt：低速起步和爬坡强，但高速反电动势高。
低 Ke / 低 Kt：高速反电动势低，但低速同扭矩需要更高电流。
```

因此，真正要解决的是**低速高 Kt 与高速低 Ke 的状态切换**，而不是单纯在高速用电流抵消永磁磁链。

### 2.2 普通 IPMSM 弱磁的限制

普通 IPMSM 通过 `id < 0` 降低合成 d 轴磁链：

```text
ψd = ψf + Ld × id
I² = id² + iq²
Pcu ≈ I²R
```

弱磁电流 `id` 不直接产生有效转矩，却占用电流容量并带来铜耗与逆变器损耗。若高速区弱磁较深，电耗可能显著增加；具体比例取决于 `Ke/Vdc/ω/Rs/Ld/Lq/Imax/温度/控制策略`，不能用单一百分比泛化。

### 2.3 混合励磁的边界

混合励磁模型：

```text
ψeff = ψPM + ψfield(if)
Ptotal = Pstator_cu + Pfield_cu + Pinverter + Piron + Pthermal_penalty
```

若混合励磁只是长期用励磁电流反向抵消永磁反电动势，本质上仍是“用电量换电压裕度”。它只有在以下不等式成立时才有工程价值：

```text
减少的弱磁铜耗 + 减少的铁耗 + 减少的电压饱和损失
>
新增的励磁铜耗 + 励磁变换器损耗 + 热管理代价 + 结构复杂度
```

因此，本轮判断把混合励磁从“主高速解法”降级为**小范围磁链微调 / 电压边界补偿 / 温度补偿候选**，不应默认替代普通弱磁。

## 3. 待定路线重排

### P0：普通 IPMSM 弱磁基线

定位：必须保留的对照组。

验证重点：

- 高速弱磁 `id` 需求；
- 同扭矩下 `I²R` 增量；
- 电压裕度、退磁裕度、热裕度；
- 与控制 LUT、S11 热/退磁保护闭环。

当前判断：产业应用成熟、成本路径相对清晰；但本项目仍需按目标设计补齐 FEA、台架、热、EMC 和故障安全验证，且它不是高速节能最优解。

### P1：高弱磁能力 IPMSM + 高压平台

定位：近期工程主线。

技术逻辑：通过更高 `Vdc`、更合理的 `Ld/Lq`、低电阻扁线、转子磁路设计与安全边界，降低深弱磁发生频率。

验证重点：

- 800V 或更高母线下的弱磁边界后移；
- 凸极率、磁钢用量、退磁风险的 Pareto；
- 高速轻载效率岛是否扩大。

### P2：两挡电驱 / 双电机差异化 Ke

定位：系统级高收益候选。

技术逻辑：直接降低高速时 `ωmotor`，而不是用电流抵消磁链。

```text
E = Ke × ωmotor
高速升挡 → ωmotor 降低 → 反电动势压力降低
```

验证重点：

- 高速巡航弱磁电流下降量；
- 变速箱效率损耗是否小于电机/逆变器节省；
- 换挡冲击、NVH、可靠性、成本和重量；
- 前后桥不同 `Ke/Kt` 或双电机分工的替代收益。

当前判断：最符合第一性原理，但工程复杂度在传动系统。

### P3：绕组重构

定位：电机本体可变 `Ke/Kt` 候选。

技术逻辑：通过串并联、星三角或多绕组切换改变等效匝数。

```text
低速：高匝数 / 串联 → 高 Kt
高速：低匝数 / 并联 → 低 Ke
```

验证重点：

- 切换前后 `Ke/Kt/R/Imax` 的定量变化；
- 高速弱磁需求下降量；
- 切换瞬态、环流、拉弧、interlock、open/short/stuck fault；
- 功率半导体矩阵或接触器的热与寿命。

当前判断：物理机制优于持续弱磁，但切换安全与车规可靠性是主风险。

### P4：可变磁化 / Memory Motor

定位：真可变磁链研究路线。

技术逻辑：通过磁化/去磁脉冲改变永磁体磁化状态，实现高/中/低磁链状态。

```text
低速：高磁链 → 高 Kt
高速：低磁链 → 低 Ke
```

验证重点：

- 磁链状态观测；
- 磁化/去磁脉冲能量；
- 高温状态漂移、不可逆退磁、转矩冲击；
- 多次循环寿命和故障回退。

当前判断：理论收益高，但状态可观测性和脉冲工程风险最大。

### P5：混合励磁

定位：辅助微调候选，不再作为单独主路线。

合理使用场景：

- 高速轻载小范围降磁链；
- 电压边界补偿；
- 温度补偿；
- 效率岛微调；
- 与普通弱磁共同降低深弱磁发生概率。

不建议定位：

- 大幅反向抵消永磁磁链；
- 长期以励磁功率换高速巡航电耗；
- 未算总损耗账前宣称优于 IPMSM 弱磁。

## 4. FE 方程式赛车启发

公开 FE / Formula Student 电车案例中常见的高速反电动势处理思路不是单点黑科技，而是系统匹配；本项目后续仍需补充来源或仿真证据：

```text
低 Ke 电机 + 高电压电池 + 合理单级减速比 + 轻度弱磁 + 赛道最高速约束
```

对本项目的启发：

1. 不应先固定一个高 `Ke` 电机，再用控制策略补救高速反电动势。
2. 应从目标车速、轮胎半径、减速比、电机最高转速、母线电压反推允许 `Ke`。
3. 弱磁应作为扩速和边界补偿，而不是长期高速节能主手段。
4. 赛车可接受短时高热和轻度弱磁，量产/民用高速巡航必须额外考虑持续电耗、NVH、热寿命和安全冗余。

## 5. 后续仿真建议

### 5.1 新增统一评分维度

所有候选路线应进入同一套 scorecard：

```text
P_total = P_cu_stator + P_cu_field + P_inverter + P_iron + P_mech + P_switching_penalty + P_thermal_penalty
```

并至少覆盖：

- 起步大扭矩；
- 中速高效巡航；
- 高速轻载巡航；
- 高速再加速；
- 低 Vdc / 高温 derating；
- 故障回退。

### 5.2 优先实验

1. **高速弱磁基线实验**：固定 `Ke/Vdc/gear_ratio`，扫描 `speed × torque` 下的 `id/iq/I²R/V_margin`。
2. **两挡传动代理实验**：比较单挡与两挡在高速轻载、再加速、变速箱损耗后的总损耗。
3. **绕组重构代理实验**：用 `turns_ratio/R/Imax/Ke/Kt` 缩放模型评估低速与高速收益，并加入切换惩罚。
4. **混合励磁小范围实验**：只允许 10%~20% 磁链调节，比较是否能减少深弱磁点，而不是大幅抵消磁链。
5. **可变磁化状态实验**：用高/中/低 `ψf` 档位叠加转矩可达性、磁化脉冲能量和状态误判惩罚。
