V2 分方案物理工程交付物矩阵

面向 12 条路线补齐 PCB、3D/CAD、控制器设计、BOM/EDA、DVP&R/DFMEA 和 gate evidence 要求。本文是摘要阅读版，完整内容以同目录 Markdown 矩阵为准。

为什么要补硬证据分类12 方案总览Gate 验收下一步

1. 为什么要补物理工程交付物

V2 每个方案若要从研究项进入工程落地，必须能回答：PCB 在哪里、3D/CAD 在哪里、控制器图在哪里、BOM/EDA 在哪里、DVP&R/DFMEA 如何验证。

硬规则：数值仿真、参数扫描和 playbook 文字不能替代 PCB、CAD、控制器图和制造交付物。

2. 统一硬证据分类

PCB

PCB / EDA

原理图、Layout、stackup、采样链、gate-disable、fault latch、Gerber、ODB++。

CAD

3D / CAD

转子/定子、壳体、冷却油路、母排、传感器安装、控制器封装。

CTRL

控制器设计

状态机、故障路径、LUT 插值、模式切换、标定 map、fallback。

DVP

BOM / DVP&R / DFMEA

BOM、制造包、供应风险、测试阈值、故障注入和发布证据。
