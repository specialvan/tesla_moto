4. 当前已知限制

  1. 默认输出仍是单 torque axis，完整 torque sweep 需要实验配置显式传入。
  2. tests/test_control_lut_generator.py 仍偏集成，完整运行时间较高。
  3. 模式分类仍基于 voltage margin 阈值，属于 v0 控制策略近似。
  4. nonlinear flux LUT 当前使用样例 LUT，不能代表真实磁饱和地图。
  5. 退磁限制仍是简化 id_min(T) 模型，不是最终硬件安全边界。
  6. schema 尚未引入 requirement trace / boundary source 字段。

5. v0.4 建议入口

  1. 拆分 control LUT generator 的轴解析、搜索和 transition validation。
  2. 引入 SearchResult 或等价结果对象。
  3. 用实验配置文件驱动 torque axis / safety boundary。
  4. 增加 schema validation 测试。
  5. 把 nonlinear flux LUT 从 sample 扩展到 FEA-derived LUT 输入链路。
