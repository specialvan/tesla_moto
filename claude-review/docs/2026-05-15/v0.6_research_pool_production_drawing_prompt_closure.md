## 3. 深度生图评审规则

1. **必须显式标注 research pool**：S07-S10 的图只能说明“需要进一步工程验证”，不能输出 engineering recommendation。
2. **必须带故障门槛**：S07 unknown-state、S08 loss-of-field、S09 illegal-state/arc、S10 per-phase isolation 必须出现在图上。
3. **必须带生产参数字段**：如 800 V、1000 A/50 μs、-20 A 到 30 A、800 V/300 A、6 phase/130 A per phase、<2 ms derate。
4. **必须保留证据链警告**：proxy simulation is not validation。
5. **不得冒充发布件**：Markdown 草案和 AI 生图只能作为真实 EDA/CAD/FEA/HIL/台架工作的输入。

## 4. 下一版 r03 生成顺序建议

1. 先生成 S09 switch matrix 和 illegal-state interlock 图，因为开关瞬态安全风险最高。
2. 再生成 S10 six-phase inverter 和 fault torque allocator，用于评审相组故障降额是否真实可实现。
3. 再生成 S08 field converter 与 loss-of-field fallback，明确励磁热和失励边界。
4. 最后生成 S07 magnetization pulse driver 与 flux state machine，集中暴露可逆磁化材料、脉冲寿命和 unknown-state 风险。
