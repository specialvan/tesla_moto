## 3. 深度生图评审规则

1. **图必须带生产参数字段**：如 `k_mod`、PM fraction、saliency ratio、bridge/rib width、thermal path、demag margin、maturity penalty。
2. **图必须带证据状态**：missing / indexed / draft / reviewed / released，不能用视觉效果掩盖证据缺口。
3. **图必须带 gate 语义**：stop、research-only、needs-more-evidence、engineering-candidate 必须分色标注。
4. **图必须可追溯**：每张图至少能追到一个 README/参数/DVP/仿真实验路径。
5. **图不得冒充真实发布件**：Markdown 草案和 AI 生图只能作为 EDA/CAD/FEA/台架工作的输入。
