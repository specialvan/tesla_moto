---

## 1. 分档定义

| 档位 | 含义 | 当前可接受文件 | 不可宣称 |
|---|---|---|---|
| `concept_drawing` | 用于工程沟通的草图、PNG、Markdown 页级图纸 | `.png`、`.md`、`.drawio` 草案 | 不能称制造图、CAD 源、EDA 源、验证报告 |
| `parameter_sheet` | 带单位、公差、来源、maturity 的参数表 | `PARAM-*.md`、`sim_binding-r02.json` | 不能称实测参数或 release calibration |
| `source_design_file` | 可被 EDA/CAD/FEA/控制工具打开和编辑的源文件 | Altium/KiCad、STEP/Parasolid/SolidWorks、Maxwell/Motor-CAD、Simulink | 未出现源文件前不得通过 G4/G5 |
| `simulation_input` | 可复现实算输入、网格、材料、边界、runner 配置 | FEA mesh、material curve、loss map、bench map、pytest fixture | synthetic/proxy 不得写成 physics validated |
| `manufacturing_release` | 可制造/可采购/可测试的发布包 | Gerber、ODB++、BOM XLSX、Pick-place、DVP result、DFMEA/FMDEA | 未有 release 文件前不得写 production-ready |

## 4. 每类真实生产文件最低要求

### 4.1 PCB / EDA

必须至少具备：

- EDA source：Altium/KiCad/OrCAD 等可编辑源文件；
- schematic PDF + netlist；
- footprint/library 版本；
- Layout + DRC/ERC 报告；
- Gerber/ODB++；
- BOM + AVL + lifecycle；
- HV/LV isolation、creepage/clearance、fault path evidence。

### 4.2 CAD / Mechanical

必须至少具备：

- STEP/Parasolid/SolidWorks/Motor-CAD 几何源；
- datum、尺寸、公差、材料；
- 装配干涉、质量、冷却接口、线束出口；
- 与 FEA/热/NVH 使用同一版本几何。

### 4.3 Controller

必须至少具备：

- 状态机源文件或 Simulink/Python block；
- 标定参数、单位、公差、maturity；
- DTC/fault fallback 定义；
- HIL 脚本和 pass/fail 阈值；
- NVM/CRC/version 发布策略。

### 4.4 FEA / Simulation input

必须至少具备：

- 几何版本、mesh、材料曲线、边界条件、求解器版本；
- lambda_d/lambda_q LUT 或 loss map 的生成配置；
- residual / correlation / bounds coverage 报告；
- 与控制 LUT 和 DVP 的版本绑定。

### 4.5 DVP&R / Manufacturing release

必须至少具备：

- DVP&R 测试脚本/工况/阈值/结果；
- HIL/bench 数据；
- DFMEA/FMDEA；
- release note、变更控制、供应商/制造字段。

## 6. 验收口径

在以下条件满足前，所有 V2 方案必须保持：

```text
production_drawing_ready=false
manufacturing_release_ready=false
engineering_validated=false
```

即使 r00/r01/r02/r03 图片、提示词、参数表和 pytest 全部通过，也只能证明概念沟通、参数绑定或代理仿真可复现，不能证明真实生产图纸完成。
